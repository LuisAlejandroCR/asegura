# Asset credits — apps/pitch/index.html

External visual assets used in the landing page. Everything else — icons,
gradients, layout, the pinned four-scene journey, the match-score engine — is
original CSS/SVG/JS built for this project. Nothing was traced, downloaded, or
reused from any reference site or video.

## On the references

`routinecoach.mp4`, `petsArea.mp4` and the Bubdle Dribbble shot were studied for
composition and motion timing only — never used as an asset source. No frames,
screenshots, graphics, copy, or branding from any of them appear in this build.
What was carried over is technique, which is not copyrightable:

- full-bleed photographic scene with UI layered over it, and a nav that collapses
  to a floating pill (from `routinecoach.mp4`)
- word-by-word blur-to-focus headline reveal, a coloured band with the subject
  photo breaking through it, and figures anchored to the band's corners
  (from `petsArea.mp4`)
- oversized editorial type, extreme scale contrast, asymmetric modular
  composition (from Bubdle)

Bubdle's purple/yellow palette was **not** used — the band, cards and type run on
Asegura's own navy/gold.
